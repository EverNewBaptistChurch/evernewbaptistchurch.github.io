# 늘새로운교회 홈페이지

모든 수정은 github.com에서 할 수 있습니다. 파일을 열고 오른쪽 위 연필 아이콘(Edit)을 누른 뒤 고치고, **Commit changes**를 누르면 1~2분 뒤 사이트에 반영됩니다.

## 매주: 예배 영상 추가

`index.html`에서 `예배 영상 목록`이라고 적힌 곳을 찾아, `<ol id="video-list">` 바로 아래 **맨 위에** 한 줄을 추가합니다.

```html
<li><a href="새 유튜브 주소">2026.11.01 주일 낮 예배</a></li>
```

맨 위 영상이 '최근 예배'로 크게 보이고, 나머지는 '지난 예배' 목록에 쌓입니다.

## 가끔: 내용 수정

- 예배 시간: `index.html`의 `예배 시간표` 주석 아래
- 연락처: `index.html`의 `연락처` 주석 아래
- 표어, 주제 말씀: `index.html`의 `표어`, `주제 말씀` 주석 아래
- 색상: `style.css` 맨 위 `:root` 부분

## 로고 넣기

`assets` 폴더에 `logo.png`라는 이름으로 업로드하면 머리글에 자동으로 나타납니다.

## 실수했을 때

파일 화면의 **History**에서 이전 버전을 확인하고 그대로 되돌릴 수 있습니다.
